# NetScope - Basic Network Sniffer

## CodeAlpha Cyber Security Internship - Task 1

### Project Overview

NetScope is a Python-based network packet sniffer developed to capture and analyze network traffic.

The tool captures packets in real time and displays useful information such as:

- Source IP Address
- Destination IP Address
- Protocol Information

This project was developed to demonstrate an understanding of network traffic analysis and packet inspection.

---

## Technologies Used

- Python 3.14.5
- Scapy
- Npcap
- Windows Command Prompt

---

## Features

- Captures live network packets
- Displays source IP addresses
- Displays destination IP addresses
- Displays protocol numbers
- Simple and lightweight implementation
